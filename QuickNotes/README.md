# QuickNotes

## Setup

1. Clone the QuickNotes repository.
2. Install the required .NET dependencies.
3. Configure the database connection and required environment settings.
4. Build the application:

dotnet build

5. Run the application:

dotnet run


## Usage

Create a new account by providing an email address and password.

The email address must be valid and the password must contain at least eight characters.

After registration, QuickNotes sends an email verification message. The account must be verified before it is treated as a verified account.
